# Zeze Portfolio

A statically generated personal portfolio built with Next.js, React, Tailwind CSS, and Lucide React.

## Architecture

- Next.js App Router
- Static Site Generation (SSG)
- Static export
- Feature-oriented frontend structure
- Repository-managed content
- No CMS
- No backend API
- No database

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The project is configured with `output: "export"` so the production build generates a static website.

## Content

Blog, Journal, Projects, Stacks, and About content are managed within the repository. Long-form content can be moved into dedicated content/MDX files as the content system is developed.
